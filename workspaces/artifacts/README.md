# 📂 ARTIFACTS DIRECTORY (RUNTIME STORAGE)

Thư mục này lưu trữ các tài liệu, đặc tả và kết quả kiểm định được sinh tự động bởi 5 Sub-Teams trong chu trình SDLC:
- `01_discovery/`: PRD chuẩn SMART, User Stories (Gherkin), Clarification Q&A, UI/UX specs.
- `02_architecture/`: Architecture design, OpenAPI 3.0 specs, ERD mermaid, STRIDE threat model, DAG tasks.
- `04_quality/`: Code review scorecard, Test summary (pytest-cov), Security audit report.
- `05_handover/`: UAT Checklist, User Manual, Release Manifest và file nén release (.zip).

> 💡 **Gợi ý:** Để xem bộ artifacts mẫu hoàn chỉnh của dự án MotoCare, xem tại: [`examples/motocare_reference/artifacts/`](../../examples/motocare_reference/artifacts/).
