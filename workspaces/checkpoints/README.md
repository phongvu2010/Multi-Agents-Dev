# 💾 CHECKPOINTS DIRECTORY (RUNTIME PERSISTENCE)

Thư mục này lưu trữ các điểm kiểm soát (checkpoints) trạng thái chu trình SDLC State Machine để hỗ trợ tính năng tạm dừng (HITL pause) và khôi phục phiên làm việc:
```bash
make resume PROJECT="Tên_Dự_Án"
```

> 💡 **Gợi ý:** Để xem file checkpoint mẫu hoàn chỉnh của dự án MotoCare, xem tại: [`examples/motocare_reference/checkpoints/`](../../examples/motocare_reference/checkpoints/).
