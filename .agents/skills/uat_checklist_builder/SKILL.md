# UAT Checklist Builder Skill

## Mục đích
Hỗ trợ Client Handover Agent soạn thảo bảng nghiệm thu để khách hàng tự tay test và xác nhận bàn giao dự án.

## Định dạng đầu ra:
- **ID Kiểm thử:** `UAT-01`, `UAT-02`...
- **Tính năng / Màn hình:** Tên chức năng thân thiện.
- **Các bước thực hiện:** Hướng dẫn từng bước (Step 1, Step 2...).
- **Kết quả mong đợi:** Người dùng sẽ thấy gì, hệ thống phản hồi thế nào.
- **Trạng thái:** [ ] Đạt / [ ] Chưa đạt / [ ] Góp ý.
